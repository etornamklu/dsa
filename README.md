# DSA

Personal practice working through [NeetCode 150](https://neetcode.io/practice) across multiple languages. The dual goal is reinforcing DSA concepts and getting fluent in each language by re-implementing the same problems. Each solution gets a `notes.md` covering the approach, complexity, and language-specific notes.
